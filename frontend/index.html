AWS Serverless Architecture

A serverless dice API exposed through Amazon API Gateway and executed by AWS Lambda.

  • Amazon API Gateway: Routes GET /roll requests to the Lambda function; CORS is enabled for browser access.
  • AWS Lambda (Node.js 24.x): Validates query parameters and generates rolls using Node.js cryptographic randomness.
  • AWS CloudWatch Logs: AWS captures Lambda runtime logs; the dashboard activity panel is a local UI log, not a live CloudWatch stream.
  • AWS SAM (Serverless Application Model): IaC template automation for reproducible cloud deployment.
